# 笔记模板规范：先做题、后对答案

> 本文件是 `cxwork.py render --style exam` 与「把作业整理成备考笔记」的**唯一格式依据**。
> 来源：库内 `通用：选择题库备考刷题.md`（题目块）＋ `通用：选择题学习.md`（解析思路）。
> 2026-11-06 与用户对齐的结论见文末「取舍记录」。

---

## 1. 目标

笔记要能**先做题、后对答案**：题干和全部选项露在外面，解析与答案收进引用块，
方便在 Obsidian 里折叠或用视线遮挡。因此「题目块」和「解析块」必须严格分层。

## 2. 题目块（严格照抄范本）

```markdown
###### 1. （单选题）Photoshop 的专用图像文件格式是（ ）。
A. EPS  
B. PSD  
C. TIFF  
D. JPEG  

> **解析**：
> * **考点**：……
> * **推导**：……
> * A. EPS：通用矢量／位图交换格式，常用于排版。
> * **B. PSD**：正确。PSD 是 PS 的源文件格式，能保留图层、通道等信息。
> * C. TIFF：通用的高品质位图格式，主要用于印刷。
> * D. JPEG：有损压缩格式，常用于网络传输。
>
> **答案**：**B**

***
```

硬要求：

1. 题目用六级标题 `######` + 序号 + `（题型）` + 题干；章节用 `###`。
   - 若目标 Vault 的 `AGENTS.md` 或同目录既有笔记另有层级惯例，**以库内为准**
     （例：`20 学科备考` 下的答案笔记用 `##` 分节）。
2. 选项 A/B/C/D **换行排列、不堆在一起**。行尾两个空格是 Markdown 硬换行——
   不加的话 Obsidian 会把四行渲染成一段。
3. 解析与答案**必须包在引用块 `>` 里**。
4. `> **答案**：**B**` 必须是引用块的**最后一行**。
5. 正确选项在辨析列表里**加粗**，写法 `> * **B. PSD**：正确。……`。
6. 每题之间用 `***` 分隔。

## 3. 解析块（学习四步的简化版）

原始学习范本是四步：定位坐标 → 无选项推导 → 证伪路径 → 变体训练。
静态题库笔记采用前三步，**省略变体训练**（它是对话陪练，放进笔记里没处作答）：

| 行 | 内容 | 要求 |
| :--- | :--- | :--- |
| `> * **考点**：` | 一句话点出底层概念／知识树分支 | 必填 |
| `> * **推导**：` | 假设没有选项，1~2 句给出推导链条的起跑线 | 必填 |
| `> * A. …` 等 | **逐选项辨析**：正确项说明为什么对，每个错误项一句话说明错在哪 | 必填，不能只写正确项 |
| `> **答案**：**X**` | 末行 | 必填 |

变体训练若确实需要，另开一份「XX 变体训练」卡片，不要塞进题库。

## 4. 判断题

选项只有 `A. 对` / `B. 错`，逐选项辨析写成「两方证伪」，避免 `A. 对：错。` 这种自相矛盾的读法：

```markdown
> * 判「对」：「互相独立」是分治法的特征；把它安到 DP 上，等于否认查表的必要。
> * **判「错」**：DP 子问题重叠才需要存表去冗余，故原命题不成立。
>
> **答案**：**B**
```

正确的一方加粗，与范本一致。

## 5. 简答题 / 操作题 / 案例题

**不套引用块**——简答看的是推导过程，遮住没意义。保持：

```markdown
###### 46. （简答题）最大子段和的 b 与 sum

**【解析】** 递推式……（表格、公式、完整推导）

**【正确答案】** $b=[6,13,\ldots]$，最大子段和 24。
```

## 6. 存疑题

教材与平台可能有第二种判法时，在题目块**之后**（引用块外、空行隔开）加折叠 callout，
两方理由都写出来，别装确定：

```markdown
> [!warning] 存疑
> 教材……但……；若平台按……判，请改为 A。
```

## 7. 库级元数据（不是本模板管的）

模板只规定**题目块**。写进 Obsidian 时，frontmatter 字段集、文件名、
双链、「相关笔记」区块一律以目标库的 `AGENTS.md` 与同目录既有笔记为准，
不要用本模板去覆盖它们。收尾照样跑 `.workbuddy/check_vault.py` 查断链。

## 8. 数据结构（`answers.json`）

`render --style exam` 需要比经典格式更多的信息，键仍是题号字符串：

```json
{
  "1": {
    "answer": "B",
    "concept": "专用图像格式的辨识",
    "derivation": "要保留图层信息，因此必须是源文件格式而非交换格式。",
    "option_notes": {
      "A": "通用矢量／位图交换格式，常用于排版。",
      "B": "正确。PSD 保留图层、通道等信息。",
      "C": "通用高品质位图格式，主要用于印刷。",
      "D": "有损压缩格式，常用于网络传输。"
    },
    "explain": "可选：整段补充说明（简答／判断题用）",
    "variant": "可选：变体训练题，默认省略"
  }
}
```

兼容规则（旧答案文件不必改造）：

| 值形态 | 行为 |
| :--- | :--- |
| `"B"` / `["A","C"]` | 只渲染答案，无解析 |
| `{"answer":"B","explain":"…"}` | 引用块里渲染一段「说明」 |
| 上表完整形态 | 渲染考点／推导／逐选项辨析 |
| 题目无 `options`（简答） | 退回第 5 节的普通段落结构 |

`option_notes` 缺省时按字母顺序生成空辨析位，不会崩。

## 9. 命令

```bash
# 抓题 → 解析 → 渲染成备考笔记
python scripts/cxwork.py run "<URL>" -c "课程名" -o ./out --style exam

# 或分步
python scripts/cxwork.py parse ./out/作业.txt -o ./out
python scripts/cxwork.py render ./out/作业.json -a answers.json --style exam -o 笔记.md
```

`--style` 默认 `classic`（旧输出），**保持不破坏已有用法**。

## 10. 取舍记录（2026-11-06 与用户对齐）

| 问题 | 结论 |
| :--- | :--- |
| 范本与库内既有笔记格式冲突 | 题目块照抄范本；frontmatter / 文件名 / 双链 / 相关笔记保留库内惯例，速抄版不动 |
| 学习四步全写会膨胀 3~4 倍 | 保留前三步，省略变体训练；存疑题保留 `[!warning]` |
| 判断题、简答题范本没覆盖 | 判断题两方证伪 + 答案末行；简答保持完整推导、不套遮挡 |
| skill 改到哪一层 | ① 本模板文档 ② 扩展答案结构 ③ `render --style exam`，默认输出不变 |
| 一键 pipeline | 暂不做：会把「逐题核对」这个必要环节藏起来 |
